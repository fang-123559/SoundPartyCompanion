## 本地构建

```powershell
.\scripts\install-dotnet.ps1
.\build.ps1 -Task All
```

可用任务：`Restore`、`Build`、`Test`、`Publish`、`All`。

发布结果位于 `artifacts/publish/win-x64`。阶段 0 只创建 Inno Setup 脚本；正式安装包将在安装 `ISCC.exe` 后由后续阶段生成。

## 隐私与边界

- 不使用小米账号或云服务。
- 不在源码中保存机器专属蓝牙地址。
- USB-C 只作为供电路径；状态通信仍依赖蓝牙连接。
- 私有协议功能必须经过实机验证后才会启用。
