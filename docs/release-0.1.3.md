适用于 Windows 11 x64 和 Xiaomi 蓝牙音箱 Pro。本版基于已通过实机验收的 0.1.2.2 内测版。

新增本地重连诊断，分别记录蓝牙连接、Windows 播放端点激活、默认输出切换和首次读到音量的时间。若重连后长时间显示 `--`，请记下发生时间，从托盘选择“导出诊断”，检查 ZIP 后随反馈一起提供。

从托盘退出正在运行的内测版或旧版，下载并运行 [Windows x64 安装包](https://github.com/fang-123559/SoundPartyCompanion/releases/download/v0.1.3/SoundPartyCompanion-Setup-0.1.3-win-x64.exe)。安装包自带运行库，附件提供 SHA256 校验文件和打包报告。
