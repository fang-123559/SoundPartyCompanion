## 安装与升级

1. 在 Windows 蓝牙设置中配对音箱。
2. 核对 `SoundPartyCompanion-Setup-0.1.1-win-x64.exe` 和同名 `.exe.sha256`。
3. 新安装或退出托盘应用后直接覆盖安装。默认当前用户安装，无需管理员权限；升级保留原设置、设备选择缓存和低电提醒去重状态。
4. 从开始菜单运行。首次使用默认启用登录启动，可在设置关闭；完全退出应用使用托盘“退出”。

安装包尚未代码签名，Windows 可能显示 SmartScreen 提示。卸载默认保留数据；明确选择“是”才删除已知设置、缓存和固定日志。原位设置窗的关闭按钮、Alt+F4 或 Esc 均返回组件；主组件的 Alt+F4 隐藏到托盘。

## 范围与限制

- 媒体按钮依赖播放器提供的 Windows 媒体能力，不承诺所有播放器均提供歌手和切歌能力。
- 电量来自 Windows HFP 属性，缓存与当前读数区分；充电识别暂缓，不根据 USB 插拔或电量上升推断充电。
- USB-C 仅作为供电路径；Bass、灯效和 HFP 切换入口隐藏。不支持多型号、TWS、Party Connect、OTA、自动更新或代码签名。
- 真正注销登录后的启动开关、另一台或干净 Windows 环境尚未验证。首次启动界面/默认设置未单独目视验收；DPI/多屏、长时间运行、诊断及低电系统通知有旧版历史验收，本轮未逐项重复。
- 按个人项目范围，以上扩展验证及真实截图按需要补充，不阻塞当前版本使用；未将其标记为本轮测试通过。
- Windows Actions 配置已提供，远程 CI 尚未运行；本轮不推送、不发布 GitHub Release。
