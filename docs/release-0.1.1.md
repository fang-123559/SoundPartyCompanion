# Sound Party Companion 0.1.1 本地发布候选版

日期：2026-10-14。尚未上传 GitHub，也未创建公开 Release。

面向 Windows 11 x64 的非官方、仅本地运行的音箱伴侣。当前已验证设备为 `Xiaomi蓝牙音箱Pro`，设计参考 `MDZ-39-DB / Xiaomi Sound Party`；不承诺其他型号。

本版迁移到 .NET 10 LTS，保持现有界面和功能范围，补充 MIT、运行库声明及可复现的打包元数据。安装包自带运行库，不需要另装 .NET。

## 使用

先在 Windows 蓝牙设置配对音箱，再运行安装包。默认当前用户安装，开始菜单启动。首次使用默认启用登录启动，可在设置关闭；退出应用使用托盘“退出”。

未签名安装包可能出现 SmartScreen 提示。SHA256 用于校验下载内容；应同时核对文件来源。卸载默认保留设置和缓存，明确选择删除才清理固定配置与应用日志；未知文件、链接和诊断 ZIP 保留。

## 已知限制

充电识别暂缓，Bass/灯效隐藏，USB-C 仅作为供电路径。单音箱，不支持多型号、TWS、Party Connect、OTA、自动更新或代码签名。媒体按钮依赖播放器提供的 Windows 媒体能力；缓存电量不等于当前读数。
